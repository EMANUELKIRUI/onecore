# Marketing application

Phase 14 completes the static public experience with platform, products,
industries, features, and pricing sections, consistent navigation/footer, and
links to the authenticated workspace. The content describes only implemented
platform foundations. It explicitly states that specialized business
products, public pricing, and public self-service registration are not yet
available; it does not fabricate backend data or product functionality.

All public content is static, so it has no API loading, error, or empty states.
Those states are provided for dynamic authenticated workspace requests.
The page uses shared `packages/ui` styles, semantic landmarks, a skip link, and
responsive navigation without hard-coded deployment domains.
